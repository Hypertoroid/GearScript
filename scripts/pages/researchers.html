Show a mechanism, a test rig or a robot the way it really moves. GearScript draws it to scale from a short description you can keep next to your code, check into your repository and render again whenever a dimension changes.

What it is good for

Method and apparatus figures

Parts are sized in real units, so the figure is to scale. Export PNG up to 4K, with a transparent background for layouts and posters.

Supplementary videos

A narrated, captioned MP4 or WebM showing how the mechanism or experiment works, often clearer than a page of stills. Captions also save as .srt or .vtt.

Interactive 3D material

A single self-contained .html player that readers can turn, pause and scrub. Put it in supplementary material or on a project page.

Talks and posters

The same project makes loops for slides (frame: slides), stills for the poster and the video for the paper.

Quick kinematic checks

See whether a linkage closes, its range of motion and where it locks before you build it, and read part positions over time as JSON for your own plots.

Grant proposals and patents

A clear moving picture of a proposed mechanism, made in an afternoon and changed in minutes when the design changes.

Reproducible figures

The figure is code. Review it like code, keep it in version control, and rebuild every figure and video from the command line, with the same engine the studio uses.

# a still for the paper, a video for the supplement, and the positions behind them
gearscript render  rig.gscript -o figure-3.png --width 3840 --time 1.5
gearscript render  rig.gscript -o supplement-1.mp4 --width 1920
gearscript sample  rig.gscript --at 0,0.5,1 --points Coupler.end.b   # JSON, for your own plots
gearscript check   rig.gscript                                        # fails the build if the model breaks

A project starts with @gearscript 1, the language version. Note the tool version you used ({{version}} today) for full reproducibility.

What it does not do

  • Motion only. GearScript solves kinematics: how connected parts move. It does not compute forces, stress, friction or dynamics, and should not be presented as a physics simulation.
  • Raster output. Figures export as PNG (and video), not SVG or PDF. Most journals accept high-resolution PNG; check yours if it asks for vector line art.
  • Beta. Version 1.0 beta. Pin the version you used, as above.

How to cite GearScript

If GearScript helped your work, a citation helps others find it. The repository includes a CITATION.cff file, so GitHub’s Cite this repository button gives APA and BibTeX. Or copy this:

@software{gearscript,
  author  = {{{ownerLast}}, {{ownerFirst}}},
  title   = {GearScript: a CSS-like language for describing and animating mechanisms},
  year    = {{{year}}},
  version = {{{version}}},
  url     = {https://gearscript.org},
  license = {Apache-2.0}
}

{{owner}}. ({{year}}). GearScript: a CSS-like language for describing and animating mechanisms (Version {{version}}) [Computer software]. https://gearscript.org
