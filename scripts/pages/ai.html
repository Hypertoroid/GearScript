For AI and agents

A language AI can write,
check and fix.

Most code an AI writes is judged by eye. GearScript code can be judged by the toolchain: it compiles or it does not, the mechanism moves as asked or it locks, and every problem comes back with a reason and a fix the model can apply. That makes it a good target for assistants, agents and models built for it.

Why it suits a model

Small and predictable

Three sections, CSS-like rules and named anchors instead of coordinates: at: Base.face.top, hinge: end.a on Crank.end.b. There is less to guess, so there is less to get wrong.

Errors that explain

More than 100 numbered errors and warnings, each with a line, a reason and a suggested fix, available as JSON. A model reads E0353 and its fix once, instead of guessing.

Answers that can be verified

Compiling, solving and sampling the motion give an exact verdict on generated code: a feedback loop for agents, and a reward signal and evaluation harness for training.

The loop

A request becomes code, the toolchain checks it, and problems go back to the model with their fixes until the mechanism compiles and moves as asked.

Request

“A crank that drives a rocker.”

The tools

The syntax prompt

A short guide to the language for any assistant. In the studio, Prompt AI copies it with your request; from the command line, gearscript prompt "a pendulum clock" prints it. Options give the one-file, chapters or patch reply format.

The JSON schema

Every shape with its properties, required properties and anchors, plus style, motion and Scene properties with examples. Print it with gearscript schema, or fetch gearscript-schema.json.

Patches

Small changes named by chapter, part and property, so a model fixes one value without rewriting the file. The studio and gearscript patch check each change, then show the problems it fixes and brings, and how the motion changes.

Motion sampling

gearscript sample solves the animation at chosen times and returns positions, rotations and the world position of named anchors, so an agent can verify that the mechanism does what was asked.

@patch 1 "Close the loop and slow the crank"
@scene
Coupler { length: 120mm => 125mm; }
@motion
replace Crank { forever: rotate: 180deg/s; } with { forever: rotate: 90deg/s; }

An MCP server for agents

Run gearscript mcp and any agent that speaks the Model Context Protocol can check, sample, patch and render projects. It offers seven tools:

  • gearscript_check: diagnostics with lines and fixes
  • gearscript_sample: positions and anchors over time
  • gearscript_patch: apply a patch and report the result
  • gearscript_render: an animated GIF of the project
  • gearscript_prompt, gearscript_spec, gearscript_schema: the language, for the agent
# once, in the repository
cd cli && npm install

# in your agent's MCP settings
{
  "mcpServers": {
    "gearscript": {
      "command": "node",
      "args": ["/path/to/GearScript/cli/gearscript.js", "mcp"]
    }
  }
}

An evaluation set

The repository includes evaluation tasks with reference answers. Score any model’s answers with one command, and use it as a baseline before you fine-tune.

gearscript eval evals/tasks.json my-model-answers/ --json
