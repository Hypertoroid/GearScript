Help a model speak machine.

GearScript is a language for describing mechanisms, and its code can be checked by a machine. We are building a model that writes it from a plain request. We are looking for the engineer who builds it.

LLM Engineer

You will build the model behind GearScript’s paid product: a written request in, a working, moving mechanism out. The language and the studio stay open source; the model and the service around it are the commercial product.

Why this problem is unusual

Most generated code is judged by eye. GearScript code is judged by the toolchain. Compiling, solving and sampling the motion give an exact, automatic verdict on every answer: a training signal and an evaluation harness that few code domains offer. More than 100 numbered errors already come with fixes, and the command line, JSON schema, patch format, MCP server and an evaluation set are in place on day one. See GearScript for AI.

What you will do

  • Data: build request and code pairs at scale from examples, mutation and models, keeping only samples the toolchain verifies.
  • Training: fine-tune and distil open models on the language, choosing base model, method and size on cost and quality.
  • Rewards: derive verifiable rewards from the compiler and solver: validity, correct motion and fidelity to the request.
  • Evaluation: grow the evaluation set into a full benchmark, with motion checks and visual assessment.
  • Editing: support targeted changes through patches addressed by chapter, part and property.
  • Serving: deliver production inference with the right latency and cost per request, including the repair loop.

Required

  • Demonstrated experience fine-tuning and evaluating language models, including a model deployed to users
  • Strong Python and PyTorch, with Hugging Face, vLLM or equivalent tools
  • Experience building training data pipelines, including synthetic data
  • A rigorous, evaluation-led approach to model development
  • Ability to work in a JavaScript codebase alongside the compiler

Preferred

  • Reinforcement learning from verifiable rewards
  • Code models, domain-specific languages, grammars or constrained decoding
  • Inference optimisation: quantisation, distillation and batching
  • Familiarity with mechanics, CAD or 3D graphics
  • Experience in early-stage teams with end-to-end ownership

Candidates with closely related experience are encouraged to apply.

The first 90 days

  • Week 2, baseline: measure leading general models, using the syntax prompt, on the evaluation set.
  • Day 30, data: a pipeline producing verified training examples, and a substantially larger evaluation set.
  • Day 60, first model: a trained model that beats the baseline on compile rate and on motion that matches the request.
  • Day 90, first release: the model behind Generate and Fix in the studio, for a first group of users.

These are indicative milestones, to be agreed with the person we hire.

How to apply

  1. Try the platform. Open the studio and the documentation.
  2. Try the baseline. Ask a general model for a mechanism using the syntax prompt (gearscript prompt), then run gearscript check on its answer.
  3. Write to us at with your CV or profile, links to relevant work, what you found, and how you would approach the first month.
