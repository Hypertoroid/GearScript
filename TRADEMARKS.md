# The Orrery name and logo

The code is open source under the Apache License 2.0. The name **Orrery** and the Orrery logo are not: section 6 of the licence leaves trademarks out. That keeps it clear to everyone which site, downloads and announcements are the official ones.

## Fine without asking

- Saying your project, course, video or plugin **works with**, **is built with** or **is for** Orrery.
- Writing about Orrery, teaching it, and making tutorials, talks and reviews.
- Using the name for files and code: the `.ms` format, a syntax highlighter, an editor extension, a parser in another language.
- Showing the logo unchanged next to a link to the official project.
- Running an unmodified or lightly modified copy of the studio for yourself, your class or your team.

## Please ask first

- Naming a product, company, domain, app or hosted service "Orrery", or anything easily confused with it ("Orrery Pro", "OrreryHub").
- Offering a public or paid hosted studio based on this code under the Orrery name or logo. Running it under your own name is fine.
- Changing the logo, or using it as your own product's logo.
- Selling merchandise with the name or logo.

A fork that changes the language or the studio substantially should use its own name, so people know which one they are using. "Based on Orrery" in its description is welcome.

To ask, open an issue or write to the maintainers. Most requests get a quick yes.
